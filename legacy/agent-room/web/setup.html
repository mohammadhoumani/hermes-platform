Agent Room Setup

Do these steps in order. It takes about 10 minutes. Tick each step when it works.

0 of 7 done

  1. Find your SSH key Your PC

    In your Downloads folder, use ssh-key-2026-09-30.key. Pick the 2 KB one whose type is KEY File.

    The 1 KB one that shows as "Microsoft Publisher" is the public key (.pub). Don't use it.

  2. Fix the key's permissions CMD · once

    Open Command Prompt (CMD) and run:

    icacls "C:\Users\Admin\Downloads\ssh-key-2026-09-30.key" /inheritance:r /grant:r "%USERNAME%:R"

    You should see Successfully processed 1 files

  3. Log in to the server CMD

    ssh -i "C:\Users\Admin\Downloads\ssh-key-2026-09-30.key" ubuntu@84.235.244.195

    The first time, type yes and press Enter.

    You should see ubuntu@hermes-server:~$

  4. Install Agent Room Server

    Paste this on the server. It installs the plugin, turns on the Hermes API server (only reachable from the server itself), starts the bridge that brings your website orders to Hermes, and restarts Hermes.

    curl -fsSL https://hermes-agent-room.vercel.app/get.sh | bash -s -- --write-key

    You should see Supabase accepted the write key., Bridge is running and Agent Room plugin is installed.

  5. Test with a fake run Server

    python3 ~/agent-room/simulate_run.py

    After about 1 minute you should see Sent to Supabase: 120 events

  6. Open your dashboard Browser

    The fake run from step 5 should be on the board. Keep this link private.

    Open dashboard

  7. Give your first order Dashboard

    On the dashboard, type what you want in the box Give the agents an order, for example:

    Create a calculator web app with a history of past results

    Press Start new project. The board starts fresh and you watch each agent work. Answer the agents' questions with Send reply, then press Approve when the BRD (gate G1) is ready. After that the agents finish everything on their own, up to the live app. Press Stop the run at any time to take back control.

If something goes wrong
Identity file ... not accessible
The path is wrong. In CMD use the full path C:\Users\Admin\..., not $HOME (that only works in PowerShell).
UNPROTECTED PRIVATE KEY FILE
Do step 2, then try step 3 again.
Permission denied (publickey)
You used the 1 KB .pub file, or the user is not ubuntu. Use the 2 KB KEY File.
Supabase check failed
Check that the whole command from step 4 was pasted, then run it again.
hermes: command not found
Run source ~/.bashrc, then step 4 again.
Dashboard says "Reconnecting"
Supabase pauses free projects after a week without use. Open supabase.com, project hermes-agent-room, and press Restore.
Order stays "waiting"
The bridge is not running. On the server: systemctl --user status agent-room-bridge. Logs: journalctl --user -u agent-room-bridge -n 50. Then run step 4 again.
Order "failed" with "Hermes refused"
The Hermes API server is off. Run step 4 again; it turns it on and restarts Hermes.
Fake run works, real run shows nothing
On the server: hermes plugins list should show agent-room as enabled. If not: hermes plugins enable agent-room then hermes gateway restart.
